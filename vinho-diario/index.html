Como conectar seu Supabase Gratuito (2 minutos):

Com o Supabase conectado, tanto os vinhos avaliados quanto os vinhos da sua Adega Virtual ficam salvos na nuvem e sincronizam entre seu celular e computador.

  1. Crie um projeto gratuito em supabase.com/dashboard.
  2. No menu lateral esquerdo do Supabase, clique em SQL Editor → New Query.
  3. Clique no botão abaixo para copiar o script da tabela, cole lá no SQL Editor e clique em Run:
  4. Depois, vá em Project Settings (⚙️) → API e copie a Project URL e a chave pública Publishable / anon.
